# Typing Speed Test | WPM and Accuracy

Typing speed test with live WPM, accuracy and color feedback, built with HTML, CSS and JavaScript.

**Live demo:** [Open the Typing Speed Test](https://soni200294.github.io/typing-speed-test/)

## Description
Built a typing speed test in JavaScript with a 30-second timer, live WPM and accuracy calculation, and per-letter green/red feedback using DOM events and setInterval. Picks a random passage on each restart. Deployed live on GitHub Pages.

## Features
- 30-second timer that starts on the first key
- Correct letters turn green, mistakes turn red
- Live WPM and accuracy
- Random passage on every restart

## Tech Used
HTML, CSS, JavaScript (DOM events, setInterval)
